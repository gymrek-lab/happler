Happler is a haplotype-based fine-mapping method that tests for associations between a trait and haplotypes (ie sets of correlated SNPs instead of individual SNPs).

Homepage: [https://happler.readthedocs.io/](https://happler.readthedocs.io/)

Visit our homepage for installation and usage instructions.
